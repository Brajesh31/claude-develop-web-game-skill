# Develop Web Game Skill

A Claude skill for planning, building, and testing browser-based games.

## Repository contents

- `SKILL.md`: core game-development workflow and instructions.
- `agents/openai.yaml`: agent metadata.
- `assets/`: game icon assets.
- `references/action_payloads.json`: action payload reference.
- `scripts/web_game_playwright_client.js`: Playwright client script for browser-game interaction and testing.

## Usage

Install the skill in the skills directory used by your Claude-compatible environment. Keep the supporting folders in their original relative locations beside `SKILL.md`.

Use this skill when developing or iterating on web games and validating gameplay in a browser.
